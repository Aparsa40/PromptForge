# PromptForge

PromptForge is a modular, production-ready chatbot platform built with a deterministic rule-based engine and an AI-ready extensible architecture.

---

## Core Features

- Rule-based matching engine
- Admin dashboard for FAQ management
- Analytics tracking
- JWT authentication
- Role-based access control
- Bulk FAQ upload
- SQLite persistence
- AI integration-ready service layer

---

## Tech Stack

Frontend:

- React 18
- Vite
- Context API

Backend:

- Node.js
- Express
- SQLite
- JWT
- bcrypt

Testing:

- Jest
- Supertest
- Vitest
- Testing Library

---

## Getting Started

Clone repository:

git clone <https://github.com/yourusername/promptforge.git>

Install dependencies:

npm run install:all

Run development:

npm run dev

---

## Testing

Backend:

cd backend
npm run test

Frontend:

cd frontend
npm run test
